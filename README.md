# 2026 런던·파리 여행 웹사이트

GitHub Pages로 제공하는 여행 일정 및 쇼핑리스트입니다.

## Pages CMS로 시각적으로 편집하기

1. **https://app.pagescms.org/** 에서 기존 GitHub 계정으로 로그인합니다.
2. Pages CMS GitHub 앱 설치 시 이 저장소(`jungyh0907/2026-London-Paris`)만 허용합니다.
3. 저장소 `main` 브랜치를 열면 `.pages.yml`에 설정된 편집 메뉴가 표시됩니다.
4. **여행 일정 · 설명과 이미지 / 쇼핑리스트 · 설명과 이미지** 메뉴에서는 글, 제목, 링크, 이미지 등을 시각적 편집기로 수정합니다.
5. **날짜별 일정표 · 셀 직접 수정 / 쇼핑 표 · 셀 직접 수정** 메뉴에서는 표를 스프레드시트형 화면에서 수정합니다.
6. 저장하면 GitHub 저장소에 바로 커밋됩니다. GitHub Pages 배포가 완료된 뒤 다른 휴대폰과 PC에서도 같은 내용을 확인할 수 있습니다.

**비용:** GitHub Pages와 Pages CMS의 무료 기능만 이용합니다. Firebase 등 외부 데이터베이스는 사용하지 않습니다. 처음에 한 번 Pages CMS GitHub 앱 설치 승인은 필요합니다.

## 파일 구조

- `index.html`, `shopping.html`: 기존 여행·쇼핑 웹페이지
- `site.js`, `site.css`: 기존 펼쳐보기, 모바일 레이아웃, 이미지 보기 및 표 렌더링
- `trip.md`, `shopping-list.md`: 표를 제외한 본문 Markdown (Pages CMS 시각적 편집)
- `tables/trip-01.csv` ~ `tables/trip-09.csv`: 날짜별 일정표
- `tables/shopping-01.csv` ~ `tables/shopping-02.csv`: 쇼핑 표
- `.pages.yml`: Pages CMS 편집 메뉴 설정
- `archive-notion/`: 변환 전 원본 두 파일 (수정하지 마세요)

## 편집 시 주의

- 본문 편집기에서 `[표 ...](tables/...csv)` 형식의 **표 연결 링크를 삭제하지 마세요**. 웹페이지는 해당 링크를 해당 표로 표시합니다.
- 표는 `tables/*.csv`에서 편집합니다. 첫 줄은 표의 머리글이며, 네 번째 '행 음영' 열은 일정표 행 음영을 유지하는 용도입니다. 일반 행은 비워두고 음영 행만 `yes`로 지정합니다.
- 표의 셀에서 줄바꿈은 일반 줄바꿈으로 입력할 수 있습니다. 굵은 글씨는 `**텍스트**`의 Markdown 표기를 사용합니다.
- 본문 Markdown에 노션 내보내기 전용 `{toggle="true"}`, `<empty-block/>` 등을 다시 넣지 마세요. 기존 펼쳐보기는 표준 제목을 기준으로 웹사이트에서 처리합니다.
- 기존 GitHub Actions 배포 워크플로는 유지합니다. 이 워크플로가 `last-updated.txt` 표시 시간도 자동으로 갱신합니다.
- 이 편집기는 웹사이트 화면과 100% 동일한 WYSIWYG가 아닙니다. 본문은 시각적 글 편집, 표는 datagrid 편집이며 실제 사이트의 푸른색 레이아웃은 별도 렌더러가 구성합니다.
